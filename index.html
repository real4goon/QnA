📖 사용 가이드

1구글 폼으로 자료 등록
자료 등록 탭의 📋 자료 등록 폼 열기 버튼 클릭 → 폼 작성 → 제출
제출하면 시트에 자동으로 추가됩니다.
2검색에 반영하기
폼 제출 후 검색 화면에서 배너의 🔄 새로고침 버튼을 누르면 즉시 반영됩니다.
3PDF 파일 연결
구글 드라이브에 PDF 업로드 → 파일 우클릭 → 공유 → 링크가 있는 모든 사용자(뷰어) → 링크 복사
폼의 파일 링크 항목에 붙여넣기
4자료 삭제
구글 시트(Form Responses 1 탭)에서 해당 행을 직접 삭제 → 프로그램에서 🔄 새로고침
5자료 수정
구글 시트에서 해당 셀 직접 수정 → 프로그램에서 🔄 새로고침
6시트 웹에 게시 (최초 1회)
구글 시트 상단 메뉴 → 파일 → 공유 → 웹에 게시 → Form Responses 1 탭 선택 → 게시
