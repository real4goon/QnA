📖 사용 가이드

1자료 등록
➕ 자료 등록 탭 → 양식 작성 → 등록하기. 관련 자료 링크는 최대 3개까지 추가할 수 있습니다.
2관련 자료 링크 추가 방법
구글 드라이브에 파일 업로드 → 우클릭 → 공유 → 링크가 있는 모든 사용자(뷰어) → 링크 복사 → 등록 폼의 링크 항목에 붙여넣기
3자료 수정·삭제
관리자 탭 → 자료 목록 → ✏️ 수정 / 🗑 삭제 버튼 클릭
4분류 추가·삭제
관리자 탭 → 🏷 분류 관리에서 새 분류를 추가하거나 기존 분류를 삭제할 수 있습니다.
