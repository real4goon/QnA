📖 사용 가이드

1자료 등록
상단 ➕ 자료 등록 탭 → 양식 작성 → 등록하기 버튼 클릭
제출 즉시 구글 시트에 저장되고, 3초 후 자동으로 반영 여부를 확인합니다.
2PDF 파일 연결
구글 드라이브에 PDF 업로드 → 공유 → 링크가 있는 모든 사용자(뷰어) → 링크 복사 → 파일 링크 항목에 붙여넣기
3자료 수정·삭제
관리자 탭 → 자료 목록 → 📊 시트 열기 → 시트에서 직접 수정/행 삭제 → 🔄 새로고침
4시트 웹에 게시 (최초 1회)
구글 시트 → 상단 메뉴 파일 → 공유 → 웹에 게시 → Form Responses 1 탭 선택 → 게시
