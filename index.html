📖 사용 가이드

1구글 계정 준비
팀 전용 구글 계정을 만드세요. 실명 인증 불필요, 전화번호 인증만 1회 필요합니다.
예시 아이디: hallym.wonmu@gmail.com
2구글 시트 만들기
구글 드라이브에서 새 스프레드시트를 만들고, 아래 형식으로 1행(헤더)을 입력하세요.
A: 제목 | B: 키워드 | C: 요약 | D: 파일링크 | E: 출처 | F: 분류 | G: 등록일 | H: 최초등록자 | I: 최종수정자

F열(분류) 입력값 — 아래 중 하나 (드롭다운 설정 권장):
법령  /  고시·기준  /  지침·FAQ  /  판례·해석  /  자체FAQ

드롭다운 설정: F열 선택 → 상단 데이터 → 데이터 유효성 검사 → 드롭다운 → 위 5가지 입력
3시트 공개 설정
상단 메뉴 → 파일 → 공유 → "링크가 있는 모든 사용자" → 뷰어로 설정
⚠️ 편집자가 아닌 뷰어로 설정해야 외부에서 읽기만 됩니다.
4시트 ID 복사
시트 주소에서 ID 부분을 복사하세요:
https://docs.google.com/spreadsheets/d/[여기가 시트ID]/edit
5이 프로그램에 시트 연결
상단의 ⚙️ 구글 시트 연결 버튼을 눌러 시트 ID를 입력하세요.
연결 후 시트에 자료를 추가하면 즉시 검색에 반영됩니다.
6PDF 파일 연결 방법
구글 드라이브에 PDF 업로드 → 파일 우클릭 → 공유 → 링크 복사
복사한 링크를 시트의 파일링크 열에 붙여넣기

⚙️ 구글 시트 연결

구글 시트 ID를 입력하면 실제 자료와 연결됩니다
시트 주소의 /d/ 와 /edit 사이에 있는 긴 문자열
