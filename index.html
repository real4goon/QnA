📖 사용 가이드

1자료 등록
상단 ➕ 자료 등록 탭 → 양식 작성 → 등록하기 클릭
제출 즉시 구글 시트 "민원자료" 탭에 저장되고, 3초 후 자동으로 반영 여부를 확인합니다.
2자료 수정
관리자 탭 → 자료 목록 → 항목의 ✏️ 수정 버튼 클릭 → 내용 변경 후 저장
3자료 삭제
관리자 탭 → 자료 목록 → 항목의 🗑 삭제 버튼 클릭 → 확인
4PDF 파일 연결
구글 드라이브에 PDF 업로드 → 공유 → 링크가 있는 모든 사용자(뷰어) → 링크 복사 → 자료 등록 시 파일 링크 항목에 붙여넣기
5시트 웹에 게시 (최초 1회)
구글 시트 → 파일 → 공유 → 웹에 게시 → "민원자료" 탭 선택 → 게시
