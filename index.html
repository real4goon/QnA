📖 사용 가이드

1접근 권한
자료 검색 · 참고 링크 열람 → 누구나 / 자료 등록 → 직원 비번(4045) / 관리자 탭 → 관리자 비번(4041)
2자료 등록
➕ 자료 등록 탭 → 양식 작성 → 등록하기. 요약 필드에서 굵기·크기·색상 서식 적용 가능합니다.
3파일 링크 추가
구글 드라이브에 파일 업로드 → 공유 → 링크가 있는 모든 사용자(뷰어) → 링크 복사 → 파일 링크 항목에 붙여넣기
4자료 수정·삭제
관리자 탭 → 자료 목록 → ✏️ 수정 / 🗑 삭제 (수정 시에도 서식 에디터 사용 가능)
5참고 링크 관리
관리자 탭 → 🔗 참고 링크 관리에서 등록·삭제. 일반 사용자는 참고 링크 탭에서 열람만 가능합니다.
