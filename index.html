📖 사용 가이드

1구글 팀 계정 준비
팀 전용 구글 계정을 만드세요. 실명 인증 불필요, 전화번호 인증 1회만 필요합니다.
예시: hallym.wonmu@gmail.com
2구글 시트 만들기
1행에 아래 헤더를 입력하세요:
A:제목 | B:키워드 | C:요약 | D:파일링크 | E:출처 | F:분류 | G:등록일 | H:최초등록자 | I:최종수정자 | J:상태

F열 드롭다운: 법령 / 고시·기준 / 지침·FAQ / 판례·해석 / 자체FAQ
J열 드롭다운: 승인대기 / 승인 / 삭제요청
3시트 웹에 게시
상단 메뉴 → 파일 → 공유 → 웹에 게시 → 게시 버튼 클릭
4시트 ID 연결
시트 주소에서 ID 복사:
https://docs.google.com/spreadsheets/d/[여기가 시트ID]/edit
관리자 탭 → 설정 → 시트 ID 입력
5승인 워크플로우
직원이 자료 등록 탭에서 작성 → 시트 입력 데이터 생성 → 구글 시트에 붙여넣기 (J열: 승인대기)
관리자가 관리자 탭 → 승인 대기에서 확인 → 구글 시트 J열을 승인으로 변경 → 새로고침
6PDF 파일 연결
구글 드라이브에 PDF 업로드 → 공유 → 링크 복사 → 시트 D열에 붙여넣기
